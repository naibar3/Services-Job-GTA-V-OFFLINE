# ServicesJob — คู่มือผู้ใช้ (ภาษาไทย)

มอดงานบริการสำหรับ **GTA V โหมดเนื้อเรื่อง (ออฟไลน์)** รับงานกลางเมืองได้อิสระ ไม่ต้องรอภารกิจ
มี 6 งาน: ลากรถ/ยึดรถ, แท็กซี่, รถทัวร์ชมวิว, รถบรรทุกส่งของ, รถพยาบาล, ตำรวจไล่ล่า
ศูนย์ส่งงานผ่านเพจเจอร์ งานเด้งเป็นการ์ดขวามือ รับด้วยคีย์บอร์ดหรือปุ่มบนพวงมาลัยได้ทันที

> สถานะเวอร์ชัน 1.1: พัฒนาและทดสอบบางส่วนบน GTA V Legacy รุ่น 1.0.3889 ดูหัวข้อ "ข้อจำกัดที่ทราบ" ท้ายคู่มือ

## 2. ติดตั้ง / อัปเดต / ถอนการติดตั้ง

### ติดตั้ง
1. ปิดเกมก่อน
2. เปิดโฟลเดอร์เกม (โฟลเดอร์ที่มี `GTA5.exe` และ `ScriptHookV.dll`)
3. คัดลอก **`ServicesJob.asi`** ไปวางในโฟลเดอร์นั้น (ที่เดียวกับ `GTA5.exe`)
   - หรือดับเบิลคลิก `install.bat` แล้วลากโฟลเดอร์เกมมาวางตามที่บอก
4. เปิดเกม เข้าโหมดเนื้อเรื่อง รอโหลดเสร็จ จะมีโฟลเดอร์ **`ServicesJob`** ถูกสร้างอัตโนมัติในโฟลเดอร์เกม (เก็บค่าตั้งค่า บันทึก และไฟล์ล็อก)
5. กด **F9** ถ้าเห็นหน้าต่างเพจเจอร์ แสดงว่าติดตั้งสำเร็จ

### อัปเดตเป็นรุ่นใหม่
ปิดเกม แล้วเขียนทับ `ServicesJob.asi` ด้วยไฟล์ใหม่ โฟลเดอร์ `ServicesJob` (ค่าตั้งค่า สถิติ) เก็บไว้ได้เลย ไม่ต้องลบ

### ถอนการติดตั้ง
ปิดเกม แล้วลบ `ServicesJob.asi` และโฟลเดอร์ `ServicesJob` ออกจากโฟลเดอร์เกม

## 3. เริ่มเล่นใน 5 ขั้นตอน

1. เข้าเกมโหมดเนื้อเรื่อง เดินหรือขับรถตามปกติ
2. รอสักครู่ ศูนย์จะส่งงานมาเป็น **การ์ดงานขวามือ** (มีเสียงเตือน) ทุก 25–70 วินาที
3. กด **Y** (หรือปุ่มพวงมาลัยที่ตั้งไว้) เพื่อรับงานทันที / กด **N** เพื่อปฏิเสธ
4. ทำตามเป้าหมายที่กล่องมุมซ้ายบน ไปตามวงแหวนและเสาแสงสีบนถนน จอดในวงเมื่อถึงจุด
5. จบงานได้เงินเข้ากระเป๋าตัวละครที่เล่นอยู่ แล้วรอรับงานต่อไป

ถ้าไม่ทันกดรับ การ์ดจะเข้าไปค้างในเพจเจอร์ (กด **F9**) เลือกรับทีหลังได้ภายใน 4 นาที

## 4. การ์ดงานสดและเพจเจอร์

### การ์ดงานสด (ขวามือ)
- งานใหม่เด้งขึ้นที่ขอบขวาของจอ แสดงประเภท ชื่อสถานที่ ปลายทาง ค่าจ้าง ระยะห่าง และแถบเวลาถอยหลัง (ค่าเริ่มต้น 20 วินาที)
- กดปุ่ม **รับงาน** → เริ่มงานทันที ไม่ต้องเปิดเมนู
- กดปุ่ม **ปฏิเสธ** หรือปล่อยหมดเวลา → ปฏิเสธทิ้ง / เก็บเข้ากล่องข้อความ (หมดเวลา)
- ปิดการ์ดสดได้ในแท็บ "ตั้งค่า" (ข้อความจะเข้าเพจเจอร์แทน)

### เพจเจอร์ (กด F9)
หน้าต่างนีออนกลางขวา ใช้เมาส์ได้ (คลิก เลื่อนล้อ) หรือคีย์บอร์ด (↑↓ เลือก, Enter ตกลง, Del ลบ, ←→ เปลี่ยนแท็บ, Esc/F9 ปิด)

| แท็บ | ใช้ทำอะไร |
|---|---|
| ข้อความ | งานที่ค้างอยู่ (สูงสุด 6 งาน หมดอายุใน 4 นาที) เลือกแล้วกด "รับงาน" หรือ "ลบ" |
| รับงาน | เปิด/ปิดประเภทงานที่ไม่อยากให้ศูนย์ส่งมา (จำค่าให้อัตโนมัติ) |
| ตั้งค่า | ตั้งปุ่ม (คีย์บอร์ด + พวงมาลัย) และเปิด/ปิดการ์ดงานสด (จำค่าให้อัตโนมัติ) |
| สถานะ | งานปัจจุบัน + ปุ่ม "ยกเลิกงานนี้" + สถิติแต่ละงานและรายได้สะสม |

> เมื่อเปิดเพจเจอร์ การควบคุมตัวละครถูกพักไว้ (เหมือนเมนูพักเกม) และเคอร์เซอร์เมาส์จะขึ้นมา

## 5. ปุ่มควบคุมและการตั้งปุ่ม (คีย์บอร์ด + พวงมาลัย)

### ปุ่มเริ่มต้น
| การกระทำ | คีย์บอร์ด | พวงมาลัย |
|---|---|---|
| เปิด/ปิดเพจเจอร์ | F9 | ไม่ได้ตั้ง |
| รับงานที่ขึ้นการ์ด | Y | ไม่ได้ตั้ง |
| ปฏิเสธงาน | N | ไม่ได้ตั้ง |
| ปุ่มกระทำ (เกี่ยวรถ/ปล่อยรถ/ดึงขึ้นถาด) | E | ไม่ได้ตั้ง |

ปุ่มคีย์บอร์ดกับปุ่มพวงมาลัย **ใช้แทนกันได้** ตั้งทั้งสองอย่างให้การกระทำเดียวกันได้

### วิธีตั้งปุ่ม
1. กด F9 → แท็บ **ตั้งค่า**
2. คลิกช่อง **คีย์บอร์ด** หรือ **พวงมาลัย** ของการกระทำที่ต้องการ ช่องจะเปลี่ยนเป็น "กดปุ่ม..."
3. กดปุ่มที่ต้องการ (ปุ่มคีย์บอร์ด หรือปุ่มบนพวงมาลัย) — Esc = ยกเลิก
4. ปุ่ม **x** ท้ายแถวล้างปุ่มของการกระทำนั้น
5. ค่าทั้งหมดบันทึกลง `ServicesJob.ini` ทันที

### เรื่องพวงมาลัย
- อ่านปุ่มจากอุปกรณ์เกมคอนโทรลเลอร์ของ Windows (WinMM) โดยไม่แย่งอุปกรณ์กับโปรแกรมอื่น เช่น WheelPlugin หรือ Pit House
- จำอุปกรณ์จากรหัสผู้ผลิตและรุ่น ไม่ผูกกับลำดับ USB
- ทดสอบแนวคิดกับพวงมาลัย Moza R3 ถ้าอุปกรณ์ของคุณไม่ถูกมองเห็น ดูหัวข้อแก้ปัญหา
- เลือกปุ่มที่ **ไม่ได้ถูกใช้** ในเกมหรือโปรแกรมพวงมาลัยของคุณ เพื่อไม่ให้ทำงานซ้อน
- ปุ่มเพจเจอร์ที่เปิดอยู่: ปุ่ม "รับงาน" ทำหน้าที่เหมือน Enter, ปุ่ม "ปฏิเสธ" เหมือน Del

### ปุ่มดีบัก (ใช้เฉพาะแก้ปัญหา)
กด **Ctrl+Alt ค้าง** แล้วกด **F7** = บันทึกชื่อชิ้นส่วนของรถใกล้ตัว / **F8** = บันทึกพิกัดและทิศที่ยืนอยู่ลง `log.txt` (ใช้เพิ่มจุดรับงาน) ปิดได้ด้วย `DebugKeys=0` ใน ini

## 6. รถของแต่ละงาน และจุดรับงาน

หลักการ: **ถ้าคุณขับรถประเภทที่งานต้องการอยู่แล้ว งานเริ่มทันที ไม่ต้องไปที่ไหน** ถ้าไม่มีรถ ให้ไปเอารถที่ "จุดรับงาน" (ไอคอนน้ำเงินบนแผนที่ มีรถจอดอยู่ 1 คัน)

| งาน | รถที่ใช้ได้ | จุดรับงาน (ค่าเริ่มต้น) |
|---|---|---|
| ลากรถ / ยึดรถ | `towtruck`, `towtruck2` และรถสไลด์ที่อยู่ในรายการ `Models=` (ค่าเริ่มต้น `flatbed`) | ลานยึดรถ Davis, Sandy Shores, Paleto Bay |
| แท็กซี่ | **รถคันไหนก็ได้** ที่มีที่นั่งผู้โดยสารว่าง (ไม่ต้องเป็นรถแท็กซี่) | อู่แท็กซี่ Downtown, สนามบิน LSIA (เป็นแค่ตัวช่วยบนแผนที่ ไม่บังคับ) |
| รถทัวร์ | `coach`, `bus` | สถานีรถทัวร์ Los Santos |
| รถบรรทุก | หัวลากที่มีรถพ่วงต่ออยู่ (เช่น `phantom`, `hauler`) | ท่าเรือ Elysian Island, คลังสินค้า La Mesa |
| รถพยาบาล | `ambulance` | โรงพยาบาล 5 แห่ง |
| ตำรวจไล่ล่า | `police`, `police2`, `police3`, `police4`, `sheriff`, `sheriff2`, `fbi`, `fbi2` | สถานีตำรวจ 8 แห่ง |

- จุดรับงานแต่ละจุดจอดรถ **1 คัน** (ปรับจำนวนได้ใน `depots.txt`) เมื่อเอารถไป รถคันใหม่จะมาแทนก็ต่อเมื่อคุณอยู่ห่างเกิน 80 เมตรและจุดว่าง
- ระบบจะดึงจุดจอดเข้า **ถนนหลักที่ใกล้ที่สุด** ภายใน 150 เมตร เพื่อให้รถออกได้เสมอ
- ป้ายและวงแหวนจุดรับงานจะโผล่เมื่ออยู่ใกล้ 60 เมตร (ปรับได้ที่ `DepotMarkerDistance`) ส่วน blip บนแผนที่เห็นตลอด

## 7. วิธีเล่นแต่ละงาน

เงินที่ได้เป็นค่าประมาณ (ปรับด้วย `PayMultiplier`) บวกโบนัสตามเงื่อนไขของแต่ละงาน

### 7.1 ลากรถ / ยึดรถ
ศูนย์สุ่มแจ้งเป็น "รถเสีย" (ลาก) หรือ "รถค้างชำระ" (ยึด) เป็นอีเวนต์เดียวกัน
1. ขึ้นรถลาก ไปที่จุดเกิดเหตุ (วงเหลือง) — พอเข้าใกล้ รถเป้าหมายจะโผล่
2. ถอยท้ายรถลากเข้าหารถเป้าหมาย แล้วกด **E** (รถ `towtruck` เกี่ยวด้วยตะขอ / รถสไลด์ดึงขึ้นถาดด้วยวินช์)
3. ขับไปลานยึดรถที่ใกล้ที่สุด (วงเขียว) จอดแล้วกด **E** เพื่อปล่อยรถ
- **ยึดรถ**: เจ้าของรถวิ่งมาตะโกนด่า ค่าจ้างสูงกว่า และมีโบนัสถ้าทำเร็ว (ภายใน ~2.5 นาที)
- ค่าจ้างโดยประมาณ: ลาก $350 + ระยะ / ยึด $900 + ระยะ

### 7.2 แท็กซี่
1. ขับรถคันไหนก็ได้ ไปรับผู้โดยสาร (วงเหลือง) พอใกล้ผู้โดยสารจะโผล่ จอดใกล้ๆ ผู้โดยสารขึ้นรถเอง
2. ขับไปส่งปลายทาง (วงเขียว) จอดให้สนิท ผู้โดยสารลง
- มิเตอร์วิ่งตามระยะทางจริง (~$80 + ระยะ)
- อีเวนต์ผู้โดยสาร (สุ่ม): **รีบ** (จับเวลา ทันได้โบนัส ×1.5), **เมา** (ขับนิ่มไม่ชนได้ทิป), **เปลี่ยนใจ** (เปลี่ยนจุดหมายกลางทาง), **หนีไม่จ่าย** (ได้แค่ 30%)
- ก่อนรับผู้โดยสาร จะสลับรถระหว่างทางได้ (งานตามรถที่คุณขับอยู่)

### 7.3 รถทัวร์ชมวิว
1. ขับรถทัวร์ (ผู้โดยสาร ~8 คนนั่งในรถแล้ว) ไปตามจุดแวะ บนแผนที่ขึ้นเลข **1 2 3 4 ...** ทุกจุด ระบบนำทางไปจุดปัจจุบัน จุดที่ผ่านแล้วหายไปจากแผนที่
2. จอดในวงเหลือง ผู้โดยสารลงไปชมวิวและถ่ายรูป **15 วินาที** (ปรับได้) มีตัวนับเวลา แล้วเดินกลับขึ้นรถเอง
3. **รถทัวร์ออกตัวไม่ได้จนกว่าผู้โดยสารจะขึ้นครบ** (ระหว่างผู้โดยสารอยู่นอกรถ ระบบจะดึงเบรกมือและตัดคันเร่ง/ถอย) ครบแล้วจึงออกรถไปจุดถัดไปได้ จุดสุดท้ายจบทัวร์ — ขับนิ่มได้โบนัส
- เส้นทางทัวร์ในไฟล์ `tours.txt` เพิ่ม/แก้เองได้

### 7.4 รถบรรทุกส่งของ
1. ขับหัวลากพร้อมพ่วงไปคลังรับสินค้า (วงเหลือง) จอดนิ่ง 6 วินาทีเพื่อโหลด
2. ขนส่งไปปลายทางไกล (วงเขียว) จอดนิ่ง 6 วินาทีเพื่อขนลง
- ประเภทสินค้า (สุ่ม): ทั่วไป / **เปราะบาง** (ชนหนักเกินจะล้มเหลว) / **ด่วน** (จับเวลา ทันได้โบนัส) / **ของเหลว**
- ค่าจ้างลดลงตามความเสียหายของพ่วง

### 7.5 รถพยาบาล
ขับอย่างเดียว ผู้ช่วย (NPC) 2 คนนั่งมากับรถ
1. ขับไปที่เกิดเหตุ (อุบัติเหตุรถชน หรือคนล้มหมดสติ) จอดใกล้ผู้ป่วย
2. ผู้ช่วยลงรถ เข็นเปลไปรับผู้ป่วยขึ้นรถเอง (ถ้าโมเดลเปลไม่มีในเกม ผู้ป่วยจะถูกย้ายขึ้นรถเฉยๆ)
3. ขับไปโรงพยาบาลที่ใกล้ที่สุด จอดในวงเขียว ผู้ช่วยนำผู้ป่วยลง
- มีมาตรวัด "อาการผู้ป่วย" ลดตามเวลาและเมื่อชนแรง ถึง 0% = ล้มเหลว ส่งไวและนิ่มได้ค่าจ้างมากกว่า

### 7.6 ตำรวจไล่ล่า
1. ขึ้นรถตำรวจ ไปยังพื้นที่คนร้าย (วงแดง) คนร้ายขับรถเร็วมากแบบบ้าระห่ำ ไม่เบรกให้อะไรเลย ชนทุกอย่างที่ขวางหน้า ฝ่าสวนเลน เปลี่ยนเส้นทางหนีไปจุดไกลๆ เรื่อยๆ และถ้าชนจนช้าลงหรือติด มันจะพุ่งกลับทันที blip กระพริบบนแผนที่
2. **ขับชนรถคนร้าย 10 ครั้ง** (นับเฉพาะที่คุณชนเอง) รถคนร้ายพังได้แต่ไม่ระเบิดก่อนครบ ยิ่งโดนชนยิ่งช้าลง
3. คนร้ายยอมจำนน ลงมายกมือ — ขับเข้าไปใกล้ จอด คนร้ายขึ้นรถ
4. ขับส่งสถานีตำรวจที่ระบบสุ่ม (วงเขียว)
- ปล่อยให้คนร้ายหนีห่างเกิน 1.4 กม. นาน 30 วินาที = ล้มเหลว ทำภายใน 6 นาทีได้โบนัส

## 8. ถาดสไลด์ (flatbed) แบบใช้เล่นอิสระ

ขับรถที่อยู่ในรายการ `Models=` (ค่าเริ่มต้น `flatbed`) โดยไม่ต้องรับงาน:
1. ถอยท้ายเข้าหา **รถคันไหนก็ได้** ที่อยู่ด้านหลัง (ห่างไม่เกิน 14 เมตร ตรงแนวท้ายรถ) และจอดให้เกือบนิ่ง
2. กด **E** (ปุ่มกระทำ) → รถคันหลังถูกวินช์ลากขึ้นถาดผ่านทางลาดจำลอง
3. ขับไปไหนก็ได้ หยุดรถแล้วกด **E** อีกครั้งเพื่อปล่อยรถลงพื้น

หมายเหตุ: ถาดของ `flatbed` ในเกมเป็นส่วนหนึ่งของตัวถัง **เอียงไม่ได้** รถจึงเลื่อนขึ้นถาดตามเส้นทางลาดที่มองไม่เห็น ระหว่างลากรถจะถูกล็อกและปิดการชน เพื่อไม่ให้ฟิสิกส์ดีดรถ ใช้ได้กับรถสไลด์มอดด้วย ใส่ชื่อโมเดล (spawn name) ใน `Models=` แล้วปรับตำแหน่งด้วย `ZShift` / `YShift` / `XShift`

### depots.txt — จุดรับงานและรถ
```
[Ambulance]
ชื่อจุด|X|Y|Z|ทิศรถ(0-360)|จำนวนคัน
```
หมวดที่ใช้ได้: `Tow`, `Taxi`, `Tour`, `Truck`, `Ambulance`, `Police` (หมวด `Police` ใช้เป็นสถานีส่งคนร้ายด้วย) จำนวนคัน 1–6
หาพิกัดใหม่: ยืนจุดที่ต้องการ กด Ctrl+Alt+F8 แล้วเปิด `log.txt` ก๊อปบรรทัด `POS ...` มาแปะ (พิกัดจะถูกดึงเข้าถนนหลักให้อัตโนมัติ)

### tours.txt — เส้นทางรถทัวร์
```
[ชื่อทัวร์]

ชื่อจุด|X|Y|Z
```
แต่ละทัวร์ต้องมีอย่างน้อย 2 จุด เรียงตามลำดับที่ขับ (จุดถูกดึงเข้าถนนใกล้สุดให้เอง)

## 10. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| กด F9 ไม่มีอะไรขึ้น | 1) มี `ServicesJob.asi` ในโฟลเดอร์เดียวกับ `GTA5.exe` ไหม 2) Script Hook V ตรงกับเกมไหม (เปิด `ScriptHookV.log` ดู) 3) มี `ServicesJob\log.txt` ไหม ถ้าไม่มี มอดไม่ถูกโหลด 4) ปุ่ม F9 อาจชนกับมอดอื่น ลองตั้งปุ่มใหม่ในไฟล์ ini |
| โหลดแล้วเกมเด้ง "SCRIPT HOOK V ERROR ... clr.dll" | มีมอด ScriptHookVDotNet (`.NET`) ค้างอยู่ในเกมและชนกัน ลองย้าย `ScriptHookVDotNet.asi` ออกชั่วคราวถ้าไม่มีมอดอื่นใช้ |
| ข้อความไทยไม่ขึ้น / เป็นกรอบเปล่า | ดู `log.txt` บรรทัด "overlay ready" ถ้าไม่มี แสดงว่า Direct3D 11 overlay ตั้งไม่สำเร็จ (เกมใช้ DX11 เท่านั้น ใช้ DX10 ไม่ได้) |
| ข้อความเบลอ | ใช้โหมดหน้าต่างที่ปรับขนาดภาพไม่ตรงกับความละเอียดเกม ให้ตั้งเกมเป็นเต็มจอหรือไร้ขอบที่ความละเอียดตรงกับจอ |
| ปุ่มพวงมาลัยตั้งไม่ติด ("กดปุ่ม..." ค้าง) | พวงมาลัยต้องปรากฏเป็นเกมคอนโทรลเลอร์ใน Windows (`joy.cpl`) และปุ่มต้องกดแล้วไฟสว่างตรงนั้น บางโปรแกรมเปลี่ยนปุ่มเป็น "ปุ่มเสมือน" ให้เลือกปุ่มอื่น หรือใช้คีย์บอร์ดแทน (กด Esc ยกเลิกการตั้ง) |
| รถที่จุดรับงานจอดผิดที่ / รถติด | แก้พิกัดใน `depots.txt` (ดูหัวข้อ 9) หรือถ้าไม่มีรถ ใช้รถประเภทนั้นจากที่อื่นขับมาก็เริ่มงานได้เลย |
| งานแท็กซี่ไปถึงจุดแล้วผู้โดยสารไม่ขึ้นรถ | ต้องอยู่ในรถ (นั่งที่คนขับ) และรถต้องมีที่นั่งผู้โดยสารว่าง จอดให้ใกล้ผู้โดยสาร (ภายใน ~16 เมตร) |
| เส้นนำทาง (GPS) หายไป | มอดตั้งเส้นนำทางซ้ำทุก 1.5 วินาที ถ้ายังหายอาจมีมอดอื่นล้างเส้นอยู่ |
| รถบรรทุกไม่เริ่มงาน | ต้องเป็นหัวลากที่มีรถพ่วง **ต่ออยู่แล้ว** (ไม่ใช่รถบรรทุกเดี่ยว) |
| อยากเริ่มงานใหม่ / ยกเลิกงาน | F9 → แท็บ สถานะ → ยกเลิกงานนี้ (รถที่ใช้อยู่ไม่ถูกลบ) |

แนบไฟล์ **`ServicesJob\log.txt`** และ **`ScriptHookV.log`** (ในโฟลเดอร์เกม) พร้อมบอกว่าทำอะไรอยู่ตอนเกิดปัญหา และรุ่นเกม (ดูใน `ScriptHookV.log` บรรทัดบนสุด)

## 11. ข้อจำกัดที่ทราบ

- ใช้ได้เฉพาะ **GTA V Legacy โหมดเนื้อเรื่อง** ที่มี Script Hook V (ไม่รองรับ GTA V Enhanced และ GTA Online)

- พิกัดจุดรับงานเป็นค่าประมาณ ระบบดึงเข้าถนนหลักให้ จึงอาจจอดบนถนนหน้าสถานที่ ไม่ใช่ในลานจอด
- ถาดสไลด์ของ `flatbed` เอียงไม่ได้ (ดูหัวข้อ 8)
- ปุ่มพวงมาลัยอ่านผ่าน WinMM ซึ่งรองรับสูงสุด 32 ปุ่มต่ออุปกรณ์ และไม่รองรับปุ่มแบบ hat/POV
- ผู้โดยสาร/NPC ของมอดเป็นประชากรสุ่มของเกม อาจดูซ้ำกันได้
- เปิดเพจเจอร์แล้วการควบคุมตัวละครถูกพักไว้ (ออกจากเมนูเพื่อขับต่อ)
- ไม่มีผลกับ GTA Online และห้ามใช้ใน GTA Online
